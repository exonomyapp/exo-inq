# Project Documentation

This directory contains the operational and architectural documentation for the project.

## Directory Structure
- `agent.md`: The Agent Operational Agreement defining the core principles, prime directive, and operational procedures for agent interactions.
- `infra/`: Infrastructure-related documentation.
- `ops/`: Standard Operating Procedures (SOPs) for routine tasks, tool usage, and environment configuration.
- `plans/`: Project planning documents and roadmaps.
- `reports/`: Generated project reports and status updates.
- `specs/`: Technical specifications for the project environment and architecture.

## Maintenance Notes
- Keep all documentation up-to-date and accurately reflecting the current state of the repository.
- Use the imperative mood for all instructional content within these files.
